# Accesibilidad

La operación principal es por voz. La pantalla completa admite doble toque para escuchar y pulsación prolongada para repetir; hay botones grandes equivalentes. Todos los controles tienen `contentDescription`, rol y estado. El contraste es blanco/amarillo sobre negro y los tamaños táctiles superan 48 dp.

TalkBack sigue siendo el lector de pantalla; VisionGuía no lo reemplaza. El servicio de accesibilidad no consume las teclas de volumen de forma permanente. TTS usa el canal de asistencia de accesibilidad y puede interrumpirse.

Validación pendiente en teléfono: recorrido lineal de TalkBack, gestos con exploración táctil activa, auriculares Bluetooth y motores TTS de distintos fabricantes.
