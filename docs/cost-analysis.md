# Análisis de costos

| Componente | Tecnología | Costo obligatorio |
|---|---|---:|
| Android | Kotlin / Android SDK | S/ 0 |
| UI | Jetpack Compose | S/ 0 |
| Visión | YOLO local / ONNX Runtime | S/ 0 |
| Voz | Vosk | S/ 0 |
| TTS | Android TextToSpeech | S/ 0 |
| Conversación | LiteRT-LM + Qwen local | S/ 0 |
| Base de datos | Room | S/ 0 |
| Preferencias | DataStore | S/ 0 |
| ESP32 | BLE / WebSocket local | S/ 0 de software |
| Mapas | OpenStreetMap | S/ 0 |

El hardware (teléfono, ESP32 y sensores) no está incluido. No se usa ninguna API por tokens, servicio cloud de visión/voz ni tarjeta de crédito obligatoria.
